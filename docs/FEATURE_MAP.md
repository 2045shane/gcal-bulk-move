# 功能地图

|功能 / 状态|输入 → 处理 → 输出|
|---|---|
|选择：已实现，DOM 脆弱|当前视图可见 `[data-eventid]` → 注入勾选框，按 ID 去重 → 已选列表|
|时间清单：已实现|用户核对填写的本地起止时间、整数偏移 → 校验、当地时间算术 → 原时间 → 新时间|
|平移执行：已实现，脆弱|已确认清单 → 逐个打开详情、编辑，核对原值，填写、派发 input/change/Tab、保存 → 成功或红色失败记录|
|批量删除：已实现，脆弱|选中日程 → 确认 + 输入「删除」→ 逐个打开并删除|
|时区文案：已实现|IANA 时区 → Intl 格式化新开始时间 → 目标时区文案与设置提示|
|免费配额：已实现|后台统一队列读取 storage → 本地日期重置，每执行扣一次 → 每天 3 次、超限 CTA|

|Calendar API：未做|不使用 API，不含 OAuth client secret；`chrome.identity` 是后续可选路线，当前未申请该权限|

## 执行边界与脆弱点

所有 Google 选择器集中在 `src/lib/selectors.js`，使用多候选、中英文 aria-label 兜底。Google DOM 变动、编辑对话框结构、语言差异会导致超时。单步轮询上限 8 秒；失败项标红，其余项目标为未执行并停止，避免在未知编辑器上继续点击。复制清单可人工补救。关闭编辑器后重新选择、生成新清单再执行。

仅操作当前视图可见事件；切换日期、事件移动到视图外或 Google 重新渲染可能导致事件找不到。重复事件「仅此 / 全部 / 后续」弹窗需要人工决定，检测到后停止，不自动选择范围。删除成功以详情关闭判断，保存成功以编辑字段关闭判断，不是服务端验证；网络故障或界面延迟可能产生不确定结果，重试前必须核对 Google 日历。无撤销或事务回滚。

日期输入目前接受原生 date、YYYY-MM-DD、YYYY/MM/DD、YYYY年M月D日（需实际值一致）；时间接受原生 time / 24 小时 H:mm。12 小时制、其他日期显示格式保守失败。全天清单结束日期不含当日；Google 如使用包含末日的显示方式会核对失败。遇到失败请手工操作。事件块不会被猜测解析成时间。

## 时间与 DST

本地时间指运行 Chrome 的操作系统时区，不一定等于 Google 日历显示时区。使用前务必确认二者一致。日期按 `setDate`、小时按 `setHours`、分钟按 `setMinutes` 计算，以墙钟时间平移；跨夏令时一天可能是 23/25 个真实小时。跳时后的目标由 JavaScript 归一到合法时间；输入处于不存在的小时会归一，清单显示实际归一结果；重复小时采用 JavaScript 的较早时刻。无偏移信息的本地输入无法表示重复小时的第二次出现。不是保证固定毫秒时长的平移。全天仅按天，时区换算不适用于全天事件。

后台 service worker 队列串行化多标签页扣费，免费用量持久化后才开始执行。浏览器故障不保证跨崩溃事务；卸载或清除本地存储会重置免费层，公开校验也可被自行生成，属于 MVP 本地门槛。

## 手动测试

1. 加载插件，在中英文 Google 日历中使用测试日历，创建普通、跨天、跨月、全天及重复事件；检查可见块勾选与去重。
2. 填入原始时间，测试 +1 小时、+1 天、-1 天、负分钟、跨年；只预览不扣费，修改偏移后必须重新生成清单。
3. 设置浏览器/日历相同时区并测试 DST 边界；核对目标时区文案，确认未改变 Google 事件时区。
4. 使用受支持日期格式的编辑页执行，核对起止时间及保存后的日历；模拟不支持格式、错误原值、只读事件、网络失败，确认红色失败记录及停止后续项目。
5. 删除时取消首次确认、输入错误文字均不得执行；在测试事件输入「删除」后核对删除。重复事件范围弹窗应停止供人工处理。
6. 连续执行三批（含失败），第四批显示 CTA；跨本地日期刷新恢复；两个标签页同时执行不得超额。
7. options 输入无效码、有效码、清除码；核对解锁不限次，清除后恢复原免费用量；复制失败清单。
